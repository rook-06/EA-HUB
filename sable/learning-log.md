# Sable — Interaction Learning Log

This is a living record of what works and what doesn't when working with Damien. Read this before every session. Update it whenever a meaningful pattern emerges — a response that landed well, an approach that missed, a behavioral pattern worth remembering.

This is not a task list or a summary. It is a record of learning.

---

## How to Use This File

**Read:** Before every response, scan for anything relevant to the current situation.

**Write:** After any interaction where Damien's response reveals something useful — a correction, a strong positive reaction, a pattern, a preference — log it here. Don't wait to be asked.

**Format each entry:**
```
[YYYY-MM-DD] OBSERVATION: what happened | APPROACH: what I tried | RESPONSE: how he reacted | ADJUSTMENT: what to do differently or keep doing
```

**What's worth logging:**
- He pushed back on how I delivered something
- He responded notably well to a specific approach
- He revealed a new preference, habit, or blind spot
- Something I tried clearly didn't land
- A pattern I'm noticing across multiple interactions

**What's not worth logging:**
- Routine task completions
- Normal back-and-forth with no signal either way
- Things already captured in personality.md
