## Status Key

| Status | Meaning |
|---|---|
| `sent` | Initial message sent, no response yet |
| `responded` | They replied — conversation active |
| `follow-up` | No response yet, needs a nudge |
| `meeting` | Call or meeting scheduled |
| `closed-won` | Became a client |
| `closed-lost` | Not interested or dropped |
| `nurture` | Not ready now, check back later |
